# Temporal Lead-Lag Relationships (GDELT × Wikipedia)

Reproduction code and data for *"Characterizing Lead-Lag Structures Between News Coverage and Public Information-Seeking on Adolescent Digital Health Topics Using GDELT and Wikipedia Page Views."*

## Data

Two daily series per focal topic, covering 2020-01-01 to 2024-12-31:

| Series | Columns | Location |
|---|---|---|
| GDELT news mentions | `date`, `mentions` | `gdelt_esports_data/<topic>.csv` |
| Wikipedia page views | `date`, `views` | `wiki_esports_data/<topic>.csv` |

Focal topics (5): `esports`, `video_game_addiction`, `loot_box`, `screen_time`, `video_game_violence`.

The `<topic>.csv` files at the repository root are the **Wikipedia** series (identical to `wiki_esports_data/`), kept for convenience only — the analysis scripts read the two data subdirectories listed above.

**Sample size (why N = 1,825).** The two series are inner-joined on `date`. The Wikipedia series covers all **1,827** calendar days of the study window; the GDELT 2.0 `timelinevolraw` timeline returned **no records for two days — 2020-10-20 and 2023-03-23** — so the merged series used in all bivariate (Granger) analyses contains **N = 1,825 daily observations**. The descriptive statistics in Table 1 of the manuscript are computed on this merged series.

Ground-truth event annotations: `<topic>_events.json` (5 topics × 16 events = 80), used as the reference events for threshold calibration.

Aggregated results: `granger_results.csv`, `summary.json`. Threshold-calibration outputs: `backtest_pooled.csv`, `backtest_by_topic.csv`.

## Robustness exports (FDR / residual diagnostics)

Generated by `export_fdr_ljungbox.py` (replicates the `granger_analysis.py` pipeline exactly; optimal lags and p-values reconcile with `granger_results.csv` to machine precision):

| File | Contents |
|---|---|
| `granger_fdr_qvalues.csv` | All 300 Granger tests (30 lags × 5 topics × 2 directions): chi-square statistic, unadjusted p, Benjamini–Hochberg q-value (q = 0.05), BH threshold, significance flag. All 10 reported optimal-lag tests remain significant after BH correction (max q = 0.00084). |
| `ljung_box_results.csv` | Ljung–Box tests on the unrestricted-model residuals at each topic's selected lag (10-lag and at-lag variants). Significant residual autocorrelation remains for 8 of 10 topic–direction pairs — daily series are strongly persistent. |
| `hac_robustness_results.csv` | Newey–West (HAC) robust Wald tests on the Granger lag coefficients at each selected lag. All 10 relationships stay significant (P < .01), i.e., conclusions are unchanged under HAC inference. |

## Robustness exports (lockdown exclusion / dummy-augmented models / cross-spectral / TLS / rolling windows)

Generated by `export_robustness.py` (same pipeline as `granger_analysis.py`; baseline lags reconcile with `granger_results.csv`). Spec notes: the ICD-11 step dummy ("June 2019 onward") is constant within the 2020–2024 sample and is dropped; COVID pulses follow the manuscript (Mar–May 2020, Nov 2020–Jan 2021, Jan–Feb 2022); the UK loot-box call for evidence is coded Sep 2020 (loot_box only) and major US mass shootings as event-date pulses (video_game_violence only).

**Identification caveat on the loot_box media→public lag.** Its p-profile is flat rather than sharply peaked: lag 20 (p = 6.9×10⁻⁴), lag 28 (7.2×10⁻⁴), lag 16 (7.9×10⁻⁴) and lag 8 (8.1×10⁻⁴) are statistically indistinguishable, so the point estimate moves with any change in specification (20 baseline, 28 without the lockdown days, 8 with dummies). The public→media direction, by contrast, is fixed at lag 1 in every specification (p ≈ 10⁻¹⁴–10⁻¹⁶).

| File | Contents |
|---|---|
| `robustness_lockdown_removal.csv` | Optimal lags after excluding the 92 lockdown days (2020-03-01 to 2020-05-31). 8 of 10 topic–direction pairs keep the identical optimal lag; loot_box media→public shifts 20→28 days and video_game_violence public→media 10→11 days; all pairs remain significant (P < .01). |
| `multivariate_dummies_lagcheck.csv` | Optimal lags re-selected with COVID and policy dummies included in both equations. 7 of 10 pairs unchanged; esports/screen_time media→public +2 days; loot_box media→public −12 days (argmin on a flat profile). All remain significant at P < .05 (largest p = .0011). |
| `multivariate_dummies_coefficients.csv` | COVID-dummy coefficients in the Wikipedia (public) equation at the selected lag, on both the raw and standardized scale, with Newey–West (HAC, 7 lags) inference on both scales. Largest standardized coefficient across all topics is +.06 (loot_box, Nov 2020–Jan 2021 pulse); gaming disorder is the only topic with all three pulses significant (standardized β = .033–.048, P = .002 to < .001). |
| `cross_spectral_coherence.csv` | Welch coherence spectrum (nperseg = 256, Hann, fs = 1/day) on log-transformed standardized series. Strongest covariation periodicities within the 2–60 day band: ~7-day and ~3.5-day cycles for all five topics. |
| `tls_events.csv` / `tls_summary_by_topic.csv` | Per-event temporal lead score, TLS = (GDELT_ratio − Wikipedia_ratio)/pooled_SD (ratios = event-day value over mean of preceding 5 days; both raw and log-scale variants). Spearman rs(|TLS|, lag asymmetry) across 80 events: raw rs = .465 (P < .0001), log rs = .389 (P = .0004). |
| `rolling_window_lootbox.csv` | 49 overlapping 365-day windows (step 30 days), public→media tests. Per-window minimum p over lags 1–30 significant at P < .05 in 37/49 windows (75.5%); fixed lag-1 tests significant in 36.7%. |

Extended topics (exploratory only, not part of the five focal topics): `adolescent_depression.csv`, `obesity.csv`, `social_media_health.csv`, `teen_mental_health.csv`, `gaming_disorder.csv`, `social_media_addiction.csv`.

## Dependencies

Python 3.10+. Install with:

```
pip install -r requirements.txt
```

**Version note (statsmodels).** Pin `statsmodels==0.15.0`, as tested. Two API details matter for this repository:

1. `grangercausalitytests` returns, for each lag, a 2-tuple whose first element is a dict keyed by the four test names (`ssr_ftest`, `ssr_chi2test`, `lrtest`, `params_ftest`) and whose second element holds the fitted-model results. `granger_analysis.py` selects the optimal lag by the minimum chi-square p-value, accessed as `gc[lag][0]["ssr_chi2test"][1]`.
2. statsmodels 0.15 **removed the `verbose` argument** from `grangercausalitytests`; the script therefore does not pass it.

## Entry points

- `granger_analysis.py` — Granger causality tests and minimum-p lag selection.
- `export_fdr_ljungbox.py` — BH-FDR q-values for all 300 tests, Ljung-Box residual diagnostics, HAC-robust Wald checks.
- `export_robustness.py` — lockdown-exclusion re-estimation, dummy-augmented multivariate checks, Welch coherence spectra, per-event TLS, loot-box rolling windows.
- `make_rolling_figure.py` — regenerates the rolling-window figure (`figures/rolling_window_lootbox.png`) from `rolling_window_lootbox.csv`.
- `backtest_thresholds.py` — threshold-calibration backtest against the annotated peak events.
- `make_figures.py` — time-series and peak-event figures.
- `event_annotation.py` — builds the `*_events.json` ground-truth event annotations.
- `gdelt_one_topic.py` / `wikipedia_esports.py` / `wiki_test.py` — data collection helpers (GDELT `timelinevolraw`, Wikimedia REST API).

## Reproduction

```
pip install -r requirements.txt
python granger_analysis.py                     # -> agenda_setting_results/granger_results.csv
python backtest_thresholds.py . out            # -> out/backtest_pooled.csv, out/backtest_by_topic.csv
```

With the data subdirectories as shipped, `granger_analysis.py` reads both series locally (no API calls are needed). The script's `WIKI_DIR` / `GDELT_DIR` constants expect exactly the two subdirectory names above.
